2008年的最后一篇

发表于2009-01-03|更新于2026-09-26|操作笔记
|总字数:610|阅读时长:1分钟|浏览量:

08年就要走了，正如她轻轻的来，挥 一挥衣袖，不带走一丝留恋。

如果要用一个字来形容2008，我选择，“快”； 如果要用一句话来形容2008，我要说，“操，他妈的忒快了”。

在2008的尾巴上回头翻看这一年的邮件，这一年的点点滴滴都涌上心头。

年初，我初到报社，一方面满大楼的跑维修；一方面忐忑的学习报社相关的知识，准备主任安排的课题。第一次独立接报修、第一次使用BDD来部署系统、第一次被主任批评、第一次上夜班、第一次给同仁做分享、第一次同大家出游……， 就在这一次次的“第一次”中，我逐步成为了技术部的一员。

这一年的收获：

1、 和技术部的诸位同事共同经历了大雪、地震、奥运、罢工等重大事件；

2、 熟悉了网络和设备情况，能够参与到基础设施的建设中去；

3、 全面提升了技术水平：

a ) 第一次参加了微软的动手实验营、参加tech·ed，以及vmware等厂商的培训活动；

b ) 参加了中软的MCSE培训；

c ) 全面学习了BDD2007的知识，开始掌握网络部署的技术；

d ) 完成图片入库工作、迁移数据、调整共享文件架构、开始负责共享文件账户权限工作以及RTX服务端维护工作；

e ) 完成正常的日常维修工作和夜班工作，与大家分享多个软件的使用。

4、 问题：

a ) 学习效率低下，没有按时完成布置的spa、usmt等学习任务；

b ) 求知欲过剩，导致学啥东西东西都是“狗熊掰棒子”，没有一个东西真正的了解、熟悉、掌握；

c ) 半路出家，真的是功底差，有很多基础性的东西，理解起来很费气力。 最后，说说2009的希望。

年年岁岁花相似，岁岁年年人不同，2008就这么的没了，生活却还要继续。 在新的一年，除却日常的工作安排外，以“实践一种生活态度“、“学习一门脚本语言“、“了解一种数据库“、“考取一门认证“、“做好一个blog“为目标 有意义的好好活，这也算“五个一工程”吧。

~~~~~~~~~~~~~~~~~~~~~~~~~~~~

PS：Happy New Year ! O( ∩_∩ )O
