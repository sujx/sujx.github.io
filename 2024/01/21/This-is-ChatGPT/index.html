VS Code插件 AI-Genie 更换Token

需求：最近更换了ChatGPT账户，需要重新设置密钥，好在对话全部保存了不必担心丢失

解决思路：

  • 打开插件的设置，逐个浏览，找到填写Token的选框
  • Google搜索 【vscode插件 genieai 更换Token】
  • 找到 vscode插件 GitHub相关地址

最终在GitHub项目下找到解决方案

链接如下：[ai-genie/chatgpt-vscode: Your best AI pair programmer in VS Code ( github.com )]( https://github.com/ai-genie/chatgpt-vscode#faq )

第一步：打开插件的命令行工具， 键入如下命令 Clear API Key

第二步重新获取Token

链接如下[API keys - OpenAI API]( https://platform.openai.com/account/api-keys )

第三步 重新发起提问，此时会要求输入密钥
