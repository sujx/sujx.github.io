「学习的逻辑-中学生高效学习策略体系」

发表于2024-01-14|更新于2026-09-26|读书笔记
|总字数:2.6k|阅读时长:7分钟|浏览量:

对于地狱级难度的中国中学应试教育，普通的认知心理学研究和学习习惯培养等简单方法对大部分中学生来说已经无效了。

学习中心论

  1. 学生应该先学会进行自主学习管理，学习的中心应该是学生自己
    1. 学生在高中阶段应当具有完善的自主学习和自主管理能力
    2. 学生在初中阶段应该开始大量的自主学习试错和修正
    3. 学生在小学阶段应该具有初步的自主学习管理意识
  2. 中学生学习的自主权
    1. 时间自主
    2. 作业自主
    3. 听课自主

学习的哲学

一切高效学习策略的基础都是高强度用脑

  1. 单位时间内产生大量的有效思维
  2. 需要高度的专注
  3. 常有一定的吃力感、痛苦感

误区

  1. 高强度用脑不是疲劳用脑
  2. 高强度用脑不是心流

高强度用脑的条件

  1. 了解高强度用脑的理念
  2. 有强大的动力去客服高强度用脑初期的痛苦
  3. 懂得具体的学习策略

高强度用脑的可实践理论

  1. 刻意练习
  2. 金字塔理论
  3. 元认知策略

结构化思维

大脑需要结构

  1. 结构化思维是一种简单易学的方法
  2. 结构化思维用途广泛、使用频率非常高
  3. 结构化思维能够带来显著的效率提升

结构化思维的本质

分类

  1. 不同的分类之间最好不要重合
  2. 各个分类加起来最好能够覆盖所有的情况

层级

  1. 事务的纵向深度
  2. 思维导图

结构化思维的落地

阅读

  1. 注意标题与目录
  2. 复杂信息结构化

知识整理

  1. 对课本已有知识点进行结构化整理，做出分类和层级
  2. 观察补充知识点，思考它属于原有课本基础知识中的哪一类的下级或者平级
  3. 按照结构化定位，在笔记本的相应位置进行知识补充

思维导图的局限性

  1. 结构化思维是一种初级策略，对于进一步提高有局限性
  2. 不仅要进行知识的整理，更多融合技巧和奇、特问题的整理

流程思维

一件复杂的事情往往是由多个流程、步骤组成，把每一个流程、步骤进行优化，做到（ 接近 ）最好，就叫做全流程优化

预习

是否预习

  1. 老师的讲课风格
  2. 自身基础知识的扎实程度
  3. 课程难度
  4. 即时反应能力

预习的方法

  1. 快速阅读课本
  2. 寻找和标记重点概念、公式和原理
  3. 尝试理解重点概念、公式和原理
  4. 记录自己的疑问，形成预习提问表

听课

课前

  1. 课间活动的意义
  2. 微观学习环境的准备

课间

  1. 专注听课
    1. 天然专注力
    2. 精力
    3. 课程难度与信息密度
      1. 跳出老师课程进行自学
      2. 高强度自主思维衍生
      3. 积极提问，不懂的地方坚决问出来
    4. 课程兴趣与重视度
  2. 理解和记忆知识
    1. 优先理解，其次记忆
    2. 提问
      1. 提问的心态——暴力突破法，勇于提问
      2. 提问的模式
        1. 不要笼统说不明白，要具体问题目的第N步没有听懂
        2. 对于知其然不知其所以然的问题，可以提问“怎么会想到从这个思路着手？”
        3. 对于好像听懂了但又不确定的，可以说”能不能举个例子“
  3. 做笔记
    1. 优先思考和理解老师讲的内容，笔记为辅助
    2. 课上做笔记要快，可以只写关键字
    3. 课尾、课后的时候间整理笔记
    4. 善用活页本，将错题集和思维导图、笔记相融合

课尾

  1. 盘点本堂课的重难点和题目
  2. 核对预习提问表
  3. 回忆和补全笔记
  4. 做练习或者记忆本堂课知识点

练习

听课是学习的中枢环节，练习是提分的灵魂

练习的策略

  1. 排序策略
  2. 单一重复策略
  3. 知识定位策略
  4. 结构化练习
  5. 分层处理

复习的策略

信息循环

有知识漏洞而不自知是学习的大忌，所以查找漏洞与弥补漏洞的方法，便是高效学习的精妙法门。信息循环的完整与高密度执行，则是处理一切知识漏洞的根基。

PDCA

概念

  1. P( Plan )：计划，确定方针和目标，确定活动计划；
  2. D( Do )：执行，实地去做，实现计划中的内容；
  3. C( Check )：检查，总结执行计划的结果，注意效果，找出问题；
    4。 A( Action )：行动，对总结检查的结果进行处理，成功的经验加以肯定并适当推广、标准化；失败的教训加以总结，以免重现，未解决的问题放到下一个PDCA循环。

实施

  1. 周而复始
  2. 大环带小环，阶梯式上升

    1. 分析现状、发现问题

    2. 分析影响因素

    3. 分析主要因素

    4. 采取措施

      1. 我们为什么要制定这个措施？
      2. 这个措施为什么要制定？
      3. 要达到什么目标？
      4. 在什么地方去做？
      5. 由谁来做？
      6. 什么时候做？
      7. 怎样做？

    5. 执行

    6. 检查

    7. 标准化

    8. 把没有解决或新出现的问题转入下一个PDCA循环中去解决

信息循环是一切成绩提高的基础

概念

  1. “听课-练习-复习-测试-听课”构成了主环，而章节融合则是分支环；
  2. 测试环节是核心环节，没有考试的世界并不美好；
  3. 在主环中，听课泛指一切学习的过程，听老师讲课、向同学提问、学习教辅书中的知识讲解都算听课；
  4. 第二三轮之后的练习和复习环节可以被省略；

测试是信息循环的核心环节

知识点掌握的全面程度是随着循环的次数而增加的，不断提升的成绩是循环的结果，而测试是信息循环得以成立的核心环节。

  1. 考试是有益的
  2. 考试就是学习的一部分，而不是学完了再去考试

提高信息循环的密度

  1. 校内增加考试，更多的单元测试和月考、双月考和季度考试
  2. 校外以自我学习为中心，建立学习节奏，自驱完成信息循环
  3. 学习中心论和高强度用脑是高效学习的核心原理

费曼技巧

原始版本

  1. 学习某个知识点或者题型
  2. 在脑中，模拟向别人讲解和教授这个知识点或者题型
  3. 如果遇到无法讲解清楚的地方，那就进行标记，这里是指标
  4. 循环步骤1~3

衍生版本

  1. 学习某个知识点或者题型
  2. 找到一个真实的人，向它讲解这个知识点或者题型
  3. 如果遇到无法讲解清楚的地方，或者此人提出的问题你无法解答，那就在相应位置进行标记
  4. 循环步骤1~3

记忆策略

为了提高记忆效率，你需要了解大脑的运作方式，并掌握记忆的基础原则与具体的执行方式。

提取策略

花费更多的时候间去尝试提取信息，把大脑中存储的信息进行输出，你的记忆效率会更高。这种方法叫做提取策略。因此，在记忆时，并不应该仅仅是反复朗读，而是应该在朗读了几遍、大约读个半熟的时候候，就开始尝试背诵出来。

特点与障碍

  1. 累：在不熟悉的情况下，强行背诵
  2. 容易产生沮丧感

使用方式与技巧

  1. 初次背诵时使用
  2. 复习记忆时使用
  3. 能够有效利用碎片时间

分散记忆

  1. 前摄抑制和后摄抑制的存在
  2. 越是零散、无逻辑的内容，越可以分散记忆

艾宾浩斯记忆曲线

  1. 艾宾浩斯记忆曲线—艾宾浩斯遗忘曲线—艾宾浩斯绝望曲线
  2. 越有意义、有逻辑性的内容，忘得越慢，从而更容易记忆

时间策略

脉冲策略

脉冲策略是一种时间使用方法，指将学习期间集中时间、集中精力冲击某个学科或者某个学科的章节或板块，争取短期突破，而不是均匀将时间分配。

集中的力量才能叫真正的力量。

具体操作

  1. 脉冲策略的使用依赖学生自我的学习中心、信息循环
  2. 脉冲策略分为短期（3小时2天）、中期（ 14周 ）和长期（ 2个月到1个学期 ）
  3. 脉冲策略不适用与学习的新阶段
  4. 脉冲策略适用于数学、物理、化学，不适用于语文、英语、生物，可适当用于政治、历史、地理

注意事项

  1. 需要配合其他学习策略
  2. 自主能力越强，脉冲策略效果越好
  3. 所有学科成绩平庸，可以使用脉冲策略形成局部优势，提高自信

宏观时间策略

微观时间策略

信息源管理

  1. 构建良好的学习生态
  2. 从教辅书中挖掘宝藏
  3. 从课外和网络寻找合适的补充

精力管理

运动改造大脑

  1. 运动能增强专注力
  2. 运动促进大脑学习时的活跃度，提高学习效率
  3. 运动能够改善成瘾行为
  4. 运动改善情绪

以最具性价比的方式提升精力

  1. 要有明显的运动效果，能够起到调节状态、提高大脑运转效率的作用
  2. 要考虑学习环节和学习节奏，方便灵活，容易执行
  3. 要易于坚持，降低中断率
    1. 以慢跑作为室外核心运动方式
    2. 以跳绳、深蹲、平板支撑等作为室内核心运动方式，主要解决久坐的问题
    3. 以各类拉伸运动和头肩活动作为课间锻炼方式
  4. 以兴趣爱好类运动作为灵活补充

睡眠的意义

  1. 充足的睡眠才能带来精力旺盛
  2. 充足的睡眠能够带来更多的大脑能量支撑高强度用脑
