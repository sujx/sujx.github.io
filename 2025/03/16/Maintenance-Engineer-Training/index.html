维保工程师赋能培训

发表于2025-03-16|更新于2026-09-26|操作笔记
|总字数:1.5k|阅读时长:4分钟|浏览量:

这是联想企业级服务技术支持团队的一个上门工程师培训内容。主要内容有三个部分：

  1. 服务与规范
  2. 上门工程师操作细则
  3. 案例复盘

服务与规范

服务的定义

  1. 为他人做事，并使他人从中受益的一种有偿或无偿的活动，不以实物形式而以劳动的形式满足他人某种特殊的需求
  2. 客户是任何商业活动中最重要的人，是工作的目的，不是让我们与之争论或较智的对象
  3. 客户的重要性

如何做好服务

  1. ITIL:服务是为客户提供价值的一种手段，使客户不用承担额外的成本和风险就可获得所期望的结果
  2. 客户最不希望发生的事情
    1. 数据丢失、应用中断
    2. 根因分析
  3. 规范定义
    1. 按照既定标准的要求进行操作，使某一行为或活动达到或超越规定的标准
    2. “三查七对一注意”
      1. 来自医疗护理一线
      2. 三查指操作前查、操作中查、操作后查
        1. 检查药品的有效期、配伍禁忌
        2. 检查药品有无变质、浑浊
        3. 检查药品的容器有无破损、瓶盖有无松动
      3. 七对：查对床号、查对姓名、查对药名、查对剂量、查对浓度、查对时间、查对用法
      4. 一注意：注意用药前的过敏史、配伍禁忌和用药后的反应

操作细则

首次联系

  1. 规范的自我介绍
    1. 使用标准话术自我介绍
    2. 自我介绍完成之后确认用户信息
    3. 确认故障机使用者
  2. 确认故障信息
    1. 工程师复述报修故障信息，并与用户确认
    2. 询问用户有无其他问题并记录
  3. 提醒数据备份
    1. 强调、提醒用户对数据进行备份
    2. 标准话术
  4. 询问地址、时间
    1. 询问用户的详细上门地址并记录
    2. 与用户初步约定上门时间
    3. 重复确认上门时间和地址信息
  5. 留下联系方式

出发前确认

  1. 再次确认时间、地址
    1. 告知用户大概抵达时间
    2. 与用户确认上门地点并安排好上门路线
  2. 故障确认、检查备件
    1. 简述故障，再次确认有无其他问题
    2. 对已申请的备件进行核对，确保备件领用正确无损坏
    3. 沟通确认用户是否已经备份数据
  3. 工程师检查携带工具
    1. 检查所带工具是否满足此维修单
    2. 有可能用户并不一定需要什么设备和线缆，要做足准备

抵达现场

  1. 整理仪容仪表
  2. 出示证件
    1. 主动出示胸卡表明身份，进行自我介绍
    2. 遵守客户机房的特殊要求或者规章制度
  3. 抵达维修场所
    1. 主动询问设备维修场所
    2. 用户引导下，跟随进入维修场所
  4. 提前抵达或迟到通知
    1. 未按照约定时间上门，需要在约定时间之前致电道歉，说明原因，并重新约定时间
    2. 提前到达，也需要提前主动与用户沟通说明

维修过程

  1. 数据免责确认、用户签字
    1. 提示维修过程中可能会导致数据丢失或者数据不可访问的风险
    2. 再次确认用户是否已经备份数据
    3. 服务单上关于数据信息，请用户阅读并签字
    4. 注重保护用户隐私
  2. 静电维护
  3. 故障检测
    1. 提前询问用户设备是否涉密，是否可以连接工程师管理口
    2. 征得用户同意后，登录管理口，查看设备日志是否与故障描述相同
    3. 先检查外观，再检查设备故障，具体操作详见工单维修建议
    4. 核查主机编号SN和工单报修设备SN是否一致
  4. 故障件更换、软件测试
    1. 按照工单维修建议进行操作，如果状态与工单描述不一致需要现场callback，联系派单cc
    2. 工程师配合cc完成维修任务
    3. 如需更换备件，工程师需要先拆箱检测备件是否有物理损伤，确认无误后放到机器旁边
    4. 告知维修方案，经客户同意后方可操作更换
    5. 维修完成后，工程师需要检查设备当前状态并收集日志
    6. 如果出现用户质疑且沟通无效、无法与用户达成一致，务必第一时间内上报
    7. 维修中出现任何风险，务必再第一时间内上报cc和项目经理备案，并于用户协商解决方案
  5. 无法修复，预约下次上门
    1. 如现场不能修复故障，收集日志反馈给cc后升级L2
    2. 确定新的解决方案并告知客户
    3. 如需再次上门，与用户预约下次上门时间

维修状态确认

  1. 设备状态确认
    1. 告知用户查看设备事件状态是否正常运行
    2. 向用户演示故障已修复
  2. 常识介绍
    1. 参考知识库技术话术向用户说明
    2. 介绍与故障相关的使用常识

案例复盘

  1. 工程师维修服务器更换内存误操作另一台设备
  2. 检查不到位，没有确认故障关联主机
  3. 需要查看故障设备日志，确保正确更换
  4. 有任何问题不能自主操作

重点强调

  1. 一切线缆只能插不能拔
  2. 严禁触碰任何开关按钮，严禁触碰非本次上架设备
  3. 严禁携带易燃易爆强辐射设备进入机房
  4. 严禁擅自移动机房内任何设备
  5. 严禁携带食品、饮料进入机房，严禁打闹
  6. 做好防静电措施，带好防静电手环、手套
  7. 紧急情况立即上报
  8. 友好沟通，互相配合，服从驻场管理
  9. 诚信
