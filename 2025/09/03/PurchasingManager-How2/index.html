供应商选择与评估

供应商种类与经济学分析

市场的要素

  1. 市场=人口+购买力+购买欲望
  2. 三个要素相互制约、缺一不可
  3. 只有三者结合才能构成现实的市场，才能决定市场的规模和容量

市场分类

  1. 个人消费者市场
    1. 购买对象：便利品、选购品、特殊品
    2. 购买因素：文化因素、社会因素、个人因素、心理因素
    3. 双因素理论、马斯洛的需要层次论
  2. 生产者市场
    1. 购买对象：生产设备、附属设备、原材料、零部件、消耗品、服务
    2. 购买决策的参与者：使用者、影响者、采购者、决定者、信息控制者
    3. 决策类型：直接购买、修正重购、新购
    4. 市场分类：完全竞争市场、垄断竞争市场、寡头市场、垄断市场
  3. 中间商市场
  4. 非盈利组织市场

供应商的信息来源

SWOT分析

  1. 外部环境分析：政策、文化、技术更新、市场开发程度、产业竞争程度、潜在供应商状况
  2. 内部环境分析：企业文化、核心竞争力、企业发展阶段、企业管理方式、组织架构、技术特性、决策制度、现存问题
  3. 波特五力模型
    1. 影响潜在进入者的因素
    2. 影响供方能力的因素
    3. 影响竞争程度的因素
    4. 影响替代品的因素
    5. 影响买方能力的因素

企业战略与供应商选择战略

橄榄型——生产显得重要

哑铃型——采购显得重要

产品的不同寿命周期的采购策略

1。 开发期：无法预测需求，需要大量促销活动。供应商参与新产品设计开发，需要制定完善供应链支持计划
2。 导入期：订货频率不稳定，产品缺乏市场认同。原材料小批量采购，供应链各环境信息共享
3。 成长期：市场需求稳定增长，竞品开始进入市场。批量生产、存货较多，服务与成本合理化
4。 成熟期：竞争加剧，市场预测准确。建立配送中心，改善服务，减少库存
5。 衰退期：需求急剧下降，价格下跌。对供应链进行调整以适应市场变化

寻找潜在供应商

  1. 从多种姓名地址目录中获得
  2. 参加展会、商业杂志、询问其他销售人员
  3. 从互联网获取

供应来源

  1. 唯一来源
  2. 单一来源
  3. 多个来源

供应商评估指标与权重

  1. 主项目权重
  2. 子项目权重
  3. 主观标准量化

全面供应商评价指标体系

  1. 八大因素：公司总体情况、合作、生产、物流、研发、采购、生态、质量体系
  2. 评估方式：各因素细化为多项指标、由多部门共同确定指标、评估结果分为ABC类、撰写总结报告进行审批并抄送各部门

供应商等级评定与管理

ABC分析法

  1. 重点管理法或者ABC分析法
  2. 根据帕累托曲线“关键的少数和次要的多数”规律，分清重点和一般，从而有区别的确定管理方式的一种分析方法
  3. 按照周转率、货物价值、订货提前期、缺货成本，把存货分为ABC三类：
    1. A类是重点管理、加强防范的关键物资
    2. C类是种类众多、价值低、存储成本低的物资
    3. B类物资介于两者之间
    4. 区分不同的管理策略

CVA管理法

  1. 又称关键因素分析法
  2. 按照存货关键性分类进行管理
    1. 最高优先级
    2. 较高优先级
    3. 中等优先级
    4. 较低优先级

采购需求预测

  1. 定性预测法
    1. Delphi法
    2. 历史类比法
    3. 专家意见法
    4. 综合判断法
  2. 定量预测法
    1. 时间序列法
      1. 移动平均法
      2. 指数平滑法
    2. 线性回归法

供应商关系冲突与协调

采购谈判技巧

采购谈判的认识

采购谈判时指企业采购商品作为买方，与卖方厂商对购销业务有关事项，如商品的品种、规格、技术标准、质量保证、订购数量、包装要求、售后服务、价格、交货日期与地点、运输方式、付款条件等进行反复磋商，谋求达成协议，建立双方都满意的购销关系。

采购谈判的程序可以分为计划和准备阶段、开局阶段、正式洽谈阶段和成交阶段。

采购谈判的挑战

谈判前准备工作

  1. 收集和分析相关信息
  2. 组建采购谈判团队
  3. 制定谈判策略
  4. 制定谈判方案

谈判实施过程

  1. 开局阶段：把握开场、开场陈述、开局策略
  2. 实质性磋商阶段：报价、讨价还价
  3. 达成协议阶段
  4. 谈判收尾工作：破裂，或者成交

SWOT工具的使用

  1. SWOT是一种用来分析组织内部的优势和劣势以及外部的机会与威胁的工具
  • Strength 优势（内部）
  • Weakness 劣势（内部）
  • Opportunity 机会（外部）
  • Threat 威胁（外部）
  1. SWOT分析的作用
    1. 分析自己（ 内部条件分析 ）
    2. 分析竞争对手
    3. 对采购方和供应商一起进行比较分析

如何实施有效的谈判

分析客户心理

  1. 优柔寡断型：改变他的观念引导去消费，一旦产生购买欲望，要马上采取行动促使对方做出决定
  2. 患得患失型：得之以喜、失之以苦，施加成交压力
  3. 讨价还价型：首先夸张杀价，注意中线法则，不要先开价，理想价为出价还价的中间价
  4. 和蔼可亲型：希望被别人接受，与客服间希望建立友好的关系而非商业关系
  5. 暴躁型：使用迂回策略，以柔克刚、息事宁人
  6. 冷漠型：不急不躁，保持理性
  7. 理智型：坦诚相告、直率交流，客观展示，少说多听，由客户自我决定
  8. 直率型：重感情，保持良好感情沟通，主动给与折扣
  9. 随性型：创造随意环境来吸引客户，多问候，并帮助挑选商品
  10. 复合型：以静制动，始终表现出糊涂、认真、虔诚的心态，静观其变，对症下药

谈判技巧

  1. 谈判前要有充分的准备
  2. 只与有权决定的人谈判
  3. 尽量在本企业办公室内谈判
  4. 不要表露对供应商的认可和对商品的兴趣
  5. 放长线钓大鱼
  6. 对等原则，人数与级别应当大致相同，避免与供应商集体谈判
  7. 采取主动，但避免让对方了解本企业的立场
  8. 必要时转移话题
  9. 避免谈判破裂，同时不要草率决定
  10. 尽量以肯定的语气与对方谈话

谈判戒律

  1. 仓促草率
  2. 玩弄权术
  3. 泄露机密

采购合同管理

采购合同概述

采购合同是企业（供方）与分供方，经过双方协商谈判一致同意而签订的“供需关系”的法律性文件，合同双方都应当遵守和履行，并且是双方联系的共同语言基础。签订合同的双方都有各自的经济目的，采购合同是经济合同，双方受“合同法”的保护和承担责任。

合同的格式

  1. 开头：名称、编号、时间、地点、地址、电话
  2. 正文：标的物、数量、质量、价格、运输、支付、交货地点、检验、保险、违约责任、解决争议方法
  3. 结尾：签名、份数、生效日期、公章

合同的内容

  1. 商品的品种、规格和数量
  2. 商品的质量和包装
  3. 商品的价格和结算方式
  4. 交货期限、地点和发送方式
  5. 商品验收办法
  6. 违约责任
  7. 合同变更和解除条件

合同的形式

  1. 口头合同
  2. 书面合同：合同书、信件、数据电文、确认书
  3. 其他形式：自动售货机的买卖行为发生

合同的价格形式

总价合同

  1. 固定总价合同
  2. 总价加激励费用合同
  3. 总价加经济价格调整合同

工料合同

也称单价合同，即只规定了卖方所提供产品的单价，根据卖方在合同执行中实际提供的产品数量计算总价，工料合同是兼具成本补偿合同和总价合同的某些特点的混合型合同，它与成本补偿合同的相似之处在于，它们是开口合同，合同价因成本增加而变化。适用范围：短期服务和小金额；工作范围未明确就要立即开始工作时，增加人员、聘请专家以及寻求其他外部支持。

成本补偿合同

成本加酬金合同也称成本补偿合同， 工程施工的最终合同价格将按照工程实际成本再加上一定的酬金进行计算。在合同签定时， 工程实际成本往往不能确定， 只能确定酬金的取值比例或者计算原则。由业主向承包单位支付工程项目的实际成本，并按事先约定的某一种方式支付酬金的合同类型。

  1. 成本加固定费用合同CPFF
  2. 成本加激励费用CPIF
  3. 成本加奖励费用CPAF

合同的管理

编写合同文本

  1. 采、供货双方的基本情况
  2. 签订合同对商品的标准必须明确规定
  3. 交货地点明确
  4. 接受货物时间应明确
  5. 必须明确双方应承担的义务和违约的责任
  6. 集中采购、分散采购与联合采购

签订合同

  1. 订约提议
  2. 接受提议
  3. 填写合同文本
  4. 履行签约手续
  5. 报请签证机关签证，或报请公证机关公证

合同履行监控

  1. 建立健全采购管理制度
  2. 实物与信息同步入库
  3. 建立控制关键点：审批、签约、承付、验收、审核、记账
  4. 实行职务分离
  5. 采购合同履行监控效果评估：价格、付款、质量、订单交货

风险防控

风险
  1. 供应商延迟交货风险
  2. 质量不合格风险
  3. 采购中道德风险
  4. 合同风险
  5. 预付款风险
策略
  1. 明确采购目的
  2. 建立供应商资格审查制度
  3. 建立保证金制度
  4. 建立采购监督管理制度

合同违约和争议解决

合同纠纷类型

  1. 无效合同纠纷
    1. 欺诈、胁迫手段订立合同
    2. 恶意串通，损害国家、集体或者第三人利益
    3. 以合法形式掩盖非法目的
    4. 损害社会公共利益
    5. 违反法律、行政法规强制规定
  2. 有效合同纠纷
    1. 合同生效的前提下，合同当事人因履行合同而发生的争议，包括合同当事人对合同内容的解释、履行及违约责任，合同的变更、中止、转让、解除、终止邓发生的一切争议
      2。 有效合同是指采购方与出卖方订立的合同符合国家的法律规定和要求，具有法律效力，受到国家法律保护的采购合同。

合同纠纷解决方式

  1. 争议解决条款
    1. 协商不成立，向有管辖权的人民法院提起诉讼
    2. 或由仲裁委员会仲裁，按照有效的仲裁规则仲裁

合同的撤销与修订

可撤销的采购合同

  1. 订立时，当事人意思不真实或者当事人在对方违背真实意思的情况下签订的合同，是相对无效合同
    1. 重大误解的采购合同
    2. 显失公平的采购合同
    3. 欺诈、胁迫的采购合同
  2. 合同签订后，可以有补充协议
    1. 另起草两份，双方签字盖章以后生效
    2. 补充协议，在签字盖章后，具有同样法律效力
      3。 要明确约定与原有合同冲突或不一致时，应以补充协议为准。原合同明示不得变更的条款，补充协议无效

供应链管理的需求管理

相关需求与独立需求

1。 独立需求是指需求变化独立于人们的主观控制能力之外，因而其数量与出现的概率是随机的、不确定的、模糊的。
2。 相关需求是指与其他需求有内在相关性的需求，根据这种相关性，企业可以精确地计算出它的需求量和需求时间，它是一种确定型需求。

需求的供应方式

  1. 推动式采购（订货点法）：减少供应商数量，整合供应渠道
    1. 质量一致性
    2. 采购管理成本下降
    3. 采购总成本下降
    4. 建立长期战略性联盟
  2. 拉动式采购（JIT）：要求供应商按时按量供货
    1. 小批量、多批次
    2. 提前期短、交货期准
    3. 质量稳定

需求的分析方法

物料需求计划

物料需求计划（MRP）由主生产进度计划和主产品层次结构逐层逐个的求出产品所有零部件的出产时间、出产数量

  1. 输入文件：主生产进度计划、物料需求清单、库存文件
